# Dot Sign

The website for **Dot Sign**, the simple, beautiful transit app: a dot-matrix subway countdown for the iPhone Home Screen and the Mac menu bar, in New York, Chicago and Los Angeles.

It's a single static page (`index.html`) served by GitHub Pages. Every sign on the page is an inline SVG drawn in the app's own 5x7 dot font, so there's no JavaScript and nothing to build.

Support page: the DotSign-support repository. Contact: shufee.app@gmail.com
